# Ticket Writer

Используй этот skill для подготовки Jira-ready описаний задач на русском.

## Как выбрать сценарий

Определи тип задачи по запросу пользователя: feature, story, task, sub-task, bug report, research, spike, risk, release, release version, sprint goal или retro action. Если тип не указан и его нельзя уверенно определить, кратко спроси, какой результат нужен. Затем прочитай соответствующий файл из `references/skills/<тип>/SKILL.md`.

Для всех сценариев сначала прочитай `references/shared/gtp-conventions.md`. Для `release-version` также прочитай `references/skills/release-version/naming.md` и `template.md`.

## Диалог

Сохраняй логику выбранного сценария: сначала задай первую порцию обязательных вопросов; после ответа — вторую, только если ответов всё ещё не хватает. Если пользователь уже дал достаточно данных, не спрашивай повторно и сразу подготовь результат. Не выдумывай факты: используй `**TODO:**` и `**Assumption:**` по правилам ядра.

В ChatGPT нет slash-команд Claude Code. Пользователь может явно вызвать этот skill через `@ticket-writer` и написать тип и описание, например: `@ticket-writer bug-report: …`. Также применяй skill автоматически, когда запрос явно соответствует его описанию.

## Результат

Верни только полезный для пользователя ответ: уточняющие вопросы либо итоговое markdown-описание, готовое к вставке в Jira. Перед отправкой выполни проверки из общего файла и шаблона выбранного типа.
