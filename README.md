# Ticket Writer

Скилл для Claude Code, который помогает команде Revenue Team писать Jira-ready описания задач через слэш-команды. Задачи в GTP часто приходят на grooming неподготовленными: размытый scope, нет AC, смешаны research и implementation, непонятно к какому продукту относится. Ticket Writer задаёт уточняющие вопросы и выдаёт готовое markdown-описание, которое можно сразу вставить в Jira.

## Команды

| Команда | Тип в Jira | Кто пользуется |
|---|---|---|
| `/feature` | Epic / крупная Story | PM, Delivery, Lead |
| `/story` | Story | PM, Delivery, Lead, Dev |
| `/task` | Task | Dev, Delivery, Lead |
| `/subtask` | Sub-task | Dev, Delivery |
| `/bug` | Bug | QA, Dev, PM |
| `/research` | Task (метка Research) | Dev, Lead, Delivery |
| `/spike` | Task (метка Spike) | Dev, Lead |

Каждая команда прогоняет задачу через несколько «линз» (роль в команде — Delivery, Engineer, Analyst, QA) и задаёт уточняющие вопросы, прежде чем выдать финальное описание. Подробности по каждой команде — в `.claude/skills/<команда>/SKILL.md`.

## Быстрый старт

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/m-lead/ticket-writer.git
   ```
2. Скопировать `.claude/skills/` в свой проект (или в `~/.claude/skills/` для глобального доступа):
   ```bash
   cp -r ticket-writer/.claude/skills ~/.claude/skills
   ```
3. Перезапустить Claude Code.
4. Проверить: набрать `/bug` — должен появиться flow (описание команды + подсказка ввести текст бага).

## Пример: вход → вопросы → выход (`/bug`)

**Вход:**
```
/bug на Glory на проде у VIP-игроков с нулевым балансом кнопка Deposit не открывает форму, воспроизводится всегда
```

**Что спросит (первая порция уже отвечена — продукт, окружение, факт/ожидание частично ясны из текста, поэтому сразу вторая порция):**
```
Уточните:
1. Шаги воспроизведения — с какого экрана начинаем, что именно нажимаем?
2. Устройство/браузер/ОС?
3. Есть ли скриншот, видео или console log?
4. Приоритет — Critical / High / Medium / Low?
```

**Ответ пользователя:**
```
1. Открыть главную → нажать кнопку Deposit в хедере
2. Chrome 126, Windows 11, десктоп
3. Есть скриншот, приложу отдельно
4. High — блокирует пополнение VIP-игрокам
```

**Выход:**
```markdown
# [Bug] Кнопка Deposit не открывает форму у VIP-игроков с нулевым балансом

**Бренд:** Glory
**Окружение:** Prod
**Устройство:** Windows 11, Chrome 126, десктоп
**Приоритет:** High

## Предусловия
VIP-статус, баланс 0.

## Description
При нажатии кнопки Deposit в хедере форма выбора платёжного метода не открывается.

## Шаги воспроизведения
1. Открыть главную страницу Glory (prod) под VIP-аккаунтом с балансом 0
2. Нажать кнопку Deposit в хедере
3. Наблюдать результат

**Частота воспроизведения:** 5/5

## Фактический результат
Форма не открывается, видимой реакции на клик нет.

## Ожидаемый результат
После нажатия кнопки Deposit открывается форма выбора платёжного метода.

## Доказательства
Скриншот прилагается отдельно.

## Technical Notes
**Assumption:** проблема связана с обработкой нулевого баланса на frontend, требует проверки.

## QA Notes
**TODO:** проверить, воспроизводится ли на Divine и Banger у VIP-аккаунтов с нулевым балансом.
```

## Как обновлять правила

Общие правила и конвенции лежат в `.claude/skills/shared/gtp-conventions.md`, флоу конкретных команд — в `.claude/skills/<команда>/SKILL.md`.

## Troubleshooting

- **Команда `/bug` и другие не появляются в Claude Code** — проверить, что `.claude/skills/` лежит в `~/.claude/skills/` или `<проект>/.claude/skills/`, и что Claude Code перезапущен после копирования.

## План пилота

Пилот: 2 разработчика + 1 QA на один спринт. Критерий успеха: ≥ 80% новых задач в GTP не требуют «допишите шаги воспроизведения / добавьте AC» на grooming.
