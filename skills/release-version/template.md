# Шаблон описания Jira Version

Чистый шаблон для `/ticket-writer:release-version` — без примеров и пояснений, для копирования.

## Имя версии

```
[Revenue/BE]: <PI> <Sprint> <Release> — <Краткое описание>
[Revenue/FE]: <PI> <Sprint> <Release> — <Проект> — <Краткое описание>
```

`Проект` — только для FE: `Админка` или `casino-web (клиент)`. Бренд в имени не указывается.

Для хотфикса:

```
[Revenue/BE]: <PI> <Sprint> <Release>-hotfix.<K> — <Описание>
[Revenue/FE]: <PI> <Sprint> <Release>-hotfix.<K> — <Проект> — <Описание>
```

## Описание версии

```markdown
## Описание

- [GTP-XXXX] …

## Сервисы

- <сервис>: tag <версия>

## План отката

- <сервис>: tag <версия>

## Подготовительные работы

- Предварительно собрать образы тегов для отката

## План по тестированию

- QA
  - …

## Deployment Info

- **Стек:**
- **Первый прод:** (только для FE)
- **Среда:** Production
- **Дата деплоя:**
- **Спринт:**
- **Ответственный за деплой:**
```
