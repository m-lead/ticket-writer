# Шаблон описания Jira Version

Чистый шаблон для `/ticket-writer:release-version` — без примеров и пояснений, для копирования.

## Имя версии

```
[Revenue/<Stack>]: <Product> — <PI> <Sprint> <Release> — <Краткое описание>
```

Для хотфикса:

```
[Revenue/<Stack>]: <Product> — <PI> <Sprint> <Release>-hotfix.<K> — <Описание>
```

## Описание версии

```markdown
## Описание

- [GTP-XXXX] …

## Сервисы

- <сервис>: tag <версия>

## План отката

- <сервис>: tag <версия>

## Подготовительные работы

- Предварительно собрать образы тегов для отката

## План по тестированию

- QA
  - …

## Deployment Info

- **Продукт:**
- **Стек:**
- **Среда:** Production
- **Дата деплоя:**
- **Окно деплоя:** до 15:00 МСК
- **Тип:**
- **Спринт:**
- **Ответственный за деплой:**
```
